0.1 / HTML

Memberi arti pada isi halaman.

Elemen memiliki tag pembuka, isi, dan biasanya tag penutup. Atribut menambahkan informasi. Pada contoh berikut, class memilih kelompok elemen; href menentukan tujuan tautan.

<article class="kartu">
  <h3>Kopi Demo</h3>
  <p>Kopi untuk latihan, bukan produk nyata.</p>
  <ul><li>Harga simulasi Rp25.000</li></ul>
  <a href="#formulir">Coba formulir</a>
</article>

Susun elemen bersarang dengan penutupan yang sesuai. Gunakan heading berurutan, paragraf untuk uraian, ul/ol untuk daftar, serta a untuk tautan. Gambar memakai img dengan src dan alt yang menjelaskan maknanya; alt kosong cocok untuk gambar dekoratif.

Dokumen dimulai dengan doctype html. Elemen html membungkus head (metadata, title, CSS) dan body (isi yang tampil). meta charset mengatur encoding; viewport membantu tampilan pada ponsel.

Praktik: di DevTools → Elements, temukan article dan h3 pada kartu di bawah. Mengubah teks h3 di Elements mengubah tampilan sementara, bukan file sumber.

0.2 / CSS

Mengatur tampilan elemen.

.kartu {
  color: #eef2ec;
  background: #223328;
  padding: 20px;
  border: 2px solid #77936b;
  margin: 16px 0;
}

.kartu adalah selector class. Setiap deklarasi memiliki property dan value. Selector h3 memilih elemen; #css memilih id tertentu. Aturan yang berlaku ditentukan cascade dan specificity, bukan semata-mata urutan baris.

Kopi Demo

Kartu contoh untuk melihat box model.

  • Harga simulasi Rp25.000

Box model tersusun dari content, padding, border, lalu margin. Padding memberi jarak ke tepi bagian dalam; margin memisahkan elemen di luar border. Font, warna, lebar, dan layout juga diatur melalui CSS.

Praktik: klik tombol pembanding, lalu periksa kartu di Elements → Styles/Computed. Hanya class dan tampilannya yang berubah; nama serta harga tetap sama. Cari padding dan margin pada box model.

0.3 / FORMULIR

Mengirim input dari browser.

<form action="/latihan-form" method="post">
  <label for="jumlah">Jumlah</label>
  <input id="jumlah" name="quantity" type="number"
         min="1" max="5" value="1" required>
  <button type="submit">Kirim simulasi</button>
</form>

action menentukan alamat tujuan; method menentukan metode HTTP. name menjadi kunci data yang dikirim. label for menghubungkan label dengan id input. Pilih type sesuai data, misalnya email atau number. textarea menerima teks beberapa baris; select menyediakan pilihan.

Praktik: klik Kirim tanpa memilih produk. Browser menahan input yang belum valid. Kemudian pilih produk, isi jumlah 2, tulis “latihan formulir”, dan kirim sambil membuka Network → All.

Temukan POST /latihan-form dan Payload → Form Data. Browser mengirim pasangan name/value menggunakan application/x-www-form-urlencoded. Server membalas halaman HTML status 200. Tidak ada database, pesanan, atau pembayaran yang dibuat.

required membantu pengguna, tetapi server tetap harus memvalidasi karena request dapat dibuat tanpa formulir. Tombol type="button" menjalankan interaksi biasa; type="submit" mengirim formulir. Contoh ini memakai submit bawaan; preventDefault pada SPA 0.6 menggantikan alur tersebut dengan JavaScript.
