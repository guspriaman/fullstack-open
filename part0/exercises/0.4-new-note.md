# 0.4 — New note diagram

**Draf pendamping belajar dengan bantuan AI; menunggu review peserta. Belum disubmit.**

Halaman Notes sudah terbuka sebelum alur dimulai. Diagram mengikuti [materi resmi](https://fullstackopen.com/en/part0/fundamentals_of_web_apps/#forms-and-http-post).

```mermaid
sequenceDiagram
    actor User as Pengguna
    participant Browser
    participant Server
    User->>Browser: Isi catatan dan klik Save
    Browser->>Server: POST /exampleapp/new_note (form data: note)
    Note right of Server: Tambahkan catatan ke array di memori, bukan database
    Server-->>Browser: 302 Found, Location: /exampleapp/notes
    Browser->>Server: GET /exampleapp/notes
    Server-->>Browser: HTML
    Browser->>Server: GET /exampleapp/main.css
    Server-->>Browser: CSS
    Browser->>Server: GET /exampleapp/main.js
    Server-->>Browser: JavaScript
    Note right of Browser: Jalankan JavaScript untuk mengambil daftar catatan
    Browser->>Server: GET /exampleapp/data.json
    Server-->>Browser: JSON daftar catatan
    Note right of Browser: Callback membentuk daftar melalui DOM
```

Urutan CSS/JavaScript disederhanakan; fokus pada ketergantungan alur, bukan durasi unduhan.
