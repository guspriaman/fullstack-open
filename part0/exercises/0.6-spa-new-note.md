Halaman SPA sudah terbuka. Mengikuti [materi resmi](https://fullstackopen.com/en/part0/fundamentals_of_web_apps/#single-page-app).

```mermaid
sequenceDiagram
    actor User as Pengguna
    participant Browser
    participant Server
    User->>Browser: Isi catatan dan klik Save
    Browser->>Browser: preventDefault() membatalkan submit bawaan
    Browser->>Browser: Buat objek catatan berisi content dan date
    Browser->>Browser: Tambahkan ke array lokal dan kosongkan input
    Browser->>Browser: redrawNotes() memperbarui DOM
    Browser->>Server: POST /exampleapp/new_note_spa, JSON content dan date
    Note over Browser,Server: Content-Type: application/json
    Server-->>Browser: 201 Created
    Note right of Browser: Tetap di halaman yang sama tanpa redirect
```

DOM diperbarui sebelum POST; tampilan baru sendiri belum membuktikan keberhasilan server.
