Coba alur pertama

  1. Jalankan frontend (4177) dan server lokal (3001).
  2. Buka Lab Brewtica, lalu DevTools → Network → Fetch/XHR.
  3. Tambah “Pemasok Latihan” dengan nomor “DEMO-003”. Amati POST, payload, respons, dan ID.
  4. Reload. Amati GET mengambil entri yang sudah tersimpan.
  5. Ketik filter. Perhatikan daftar berubah tanpa request API baru.
